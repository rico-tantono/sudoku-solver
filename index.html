How Sudoku works

Sudoku is a logic puzzle on a 9×9 grid. You never need to calculate anything. You only need to decide which digit can go where.

The digits already on the grid are clues. A well-made puzzle has exactly one solution, so you never have to guess blindly.

How to solve one

Work through these in order. Each one is harder than the last, and most puzzles are solved by the first four.

  1. Scan for a nearly full unit

    Look at rows, columns, and boxes that are almost complete. If only one digit is missing, it goes in the last empty cell.

  2. Write down candidates

    For each empty cell, list the digits that don’t already appear in its row, column, or box. These are your pencil marks.

  3. Find a naked single

    A cell with only one candidate must hold that digit. The solver reports this as “Only digit that fits this cell.”

  4. Find a hidden single

    If a digit can go in only one cell of a row, column, or box, it belongs there, even if that cell has other candidates.

  5. Remove candidates with pairs

    If two cells in the same unit share the same two candidates, those digits belong to those cells. Remove them from the unit’s other cells.

  6. Guess and check

    When logic runs out, pick a cell with two candidates and try one. If you hit a contradiction, undo it and try the other. This is called backtracking.

How this solver works

It uses the last step, but cleverly. It always picks the empty cell with the fewest legal digits, tries them one by one, and undoes any choice that leads to a dead end. The steps you see are only the moves that stay in the final answer.
